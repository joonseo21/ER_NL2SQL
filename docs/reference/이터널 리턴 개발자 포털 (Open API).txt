1. 소개
1.1. 요청 보내기
모든 사용자 요청에는 x-api-key가 포함되어야 합니다.
이 x-api-key는 최초 로그인 후 발급된 키입니다.
우측 상단의 "My Dashboard"에서 발급된 API 키를 확인할 수 있습니다.

파이썬 예시

import requests
import json

url = "https://open-api.bser.io/v1/user/nickname?query=*USER_NICKNAME*"
# 기본 UID 조회 엔드포인트 사용 예.

header = { "x-api-key" : "YOUR_API_KEY"}

# 헤더에는 x-api-key가 반드시 포함되어야 합니다.
res = requests.get(url, headers=header)
1.2. 표준 응답 래퍼
파이썬 예시

import requests
>>> res = requests.get("YOUR_URL_HERE", headers=header)
>>> res.json()
{
    "code": 200,
    "message": "Success",
    "data":
        { "YourData" : True }
        # 일부 엔드포인트는 data 대신 리소스별 키를 사용합니다
}
일반적인 응답은 항상 "code", "message", 혹은 "data"라는 이름의 페이로드 키를 포함합니다.

2. 엔드포인트
2.1. 사용자
2.1.1. UID 조회 (v1)
대부분의 엔드포인트는 사용자를 식별하기 위해 UID가 필요합니다.
주의: UID는 영구적이지 않습니다 — 사용자가 닉네임을 변경할 때마다 달라집니다.

엔드포인트
/v1/user/nickname?query={nickname}

매개변수
매개변수	타입	설명
nickname

string

플레이어의 현재 인게임 닉네임.

응답 (200)
{
    "code":200,
    "message":"Success",
    "user":{
        "uid": "eff12455D22Xj91",
        "nickname":"ANONYMOUS"
        }
}
데이터 정의
이 엔드포인트는 UID와 조회된 닉네임을 반환합니다.

2.1.2. 사용자 경기 목록 조회 (v1)
지난 90일 동안 사용자가 플레이한 모든 경기를 나열합니다.
사용자가 닉네임을 변경한 경우, 변경 이전에 플레이한 경기는 이 검색 결과에 포함되지 않습니다.

엔드포인트
/v1/user/games/uid/{uid}

매개변수
이름	타입	설명
userId

string

GET UID 엔드포인트로 획득한 UID. UID 조회 (v1)

응답 (200)
{
    "code":200,
    "message":"Success",
    "userGames":[
        BattleUserResult,
        BattleUserResult
        ]
}
데이터 정의
이 엔드포인트는 BattleUserResult 데이터 목록을 반환합니다.
자세한 내용은 BattleUserResult를 참조하세요.

2.4. 기타
2.4.1. 게임 데이터 조회 (v2)
엔드포인트
/v2/data/{metaType}

매개변수
매개변수	타입	설명
metaType

string

조회하려는 데이터의 종류입니다.
hash를 입력하면 사용 가능한 모든 metaType을 확인할 수 있습니다.
metaType에는 테이블 이름을 입력합니다.

해시 응답
{
    "code":200,
    "message":"Success",
    "data": {
      "ActionCost" : 1525244,
      "Area" : 41524422
      }
}
해시 조회는 테이블 이름과 해당 해시 코드의 딕셔너리를 반환합니다.
키를 metaType 입력으로 사용하세요.
예: /v2/data/ActionCost

테이블 응답
{
    "code":200,
    "message":"Success",
    "data":
        [
            { "code" : 1525244, "name" : "example", "prefabName" : "something", "damage" : "0.f"},
            { "code" : 1525245, "name" : "example2", "prefabName" : "something2", "damage" : "0.f"}
        ]
}
데이터는 딕셔너리 목록으로 반환됩니다. 각 딕셔너리는 한 행을 의미합니다.

MonsterDropGroup

DropGroup

VFCredit

Season

현재 시즌을 표시합니다.

데이터 가져오기 (권장)
다음은 l10n 데이터를 가져오는 예시 코드입니다.

파이썬
import requests, json

MONSTER_PREFIX = "Monster/Name/"

search_monster_key = MONSTER_PREFIX + "MONSTER CODE TO SEARCH"

monster_name = l10n[search_monster_key]

4.6. 스킬 코드
