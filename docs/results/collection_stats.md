따라서 265는 랭커들의 전체 플레이 횟수가 아니라 현재 랭커 UID의 경기 목록에서 발견한
스쿼드·랭크 조건의 고유 경기 수다.

ER API 문서는 최근 90일까지 조회할 수 있다고 설명하지만, 이번 원본 `startDtm` 관측 범위는
2026-09-10 07:52:54부터 2026-09-25 16:38:10(KST)까지였다. 90일은 최대 조회 범위이며 실제
반환량은 시즌, 닉네임 변경, 플레이 활동과 수집 필터의 영향을 받는다.

`games.start_dtm`은 처음에 265건 모두 NULL이었다. 원본 값이 `+0900` 형식이라 `LocalDateTime`
파서가 처리하지 못했기 때문이며, 매퍼를 `OffsetDateTime`으로 고치고 컬럼을 `timestamptz`로
바꿔 `raw`에서 backfill했다(2026-09-25). 적용 후 265건 모두 값이 있고 최소·최대가 위 관측
범위와 일치한다. 자세한 내용은 `start_dtm_backfill.md` 참조.
