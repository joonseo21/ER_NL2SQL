| 질문 | 가드 | 실행 | 결과 행 | 소요시간 | 실패 분류 |
|---|---|---|---:|---:|---|
| 수집된 경기는 몇 판이야? | 미도달 | 실패 | 0 | 로그 참조 | Gemini `503 UNAVAILABLE`(일시적 고수요) |
| 가장 많이 픽된 실험체 상위 10개는? | 미실행 | 미실행 | - | - | - |

| 랭커와 비랭커의 실험체별 평균 킬 차이는? | 미실행 | 미실행 | - | - | - |
| 같은 실험체라도 무기에 따라 평균 순위가 다른가? | 미실행 | 미실행 | - | - | - |

추정값은 쓰지 않는다.

## 실행 메모

- `gemini-flash-latest` 첫 실행에서 모델 고수요에 따른 `503 UNAVAILABLE`을 관측했다.
- 직접 `Models.generate_content` 호출의 AFC 경고를 없애기 위해 `Chat.send_message`로 전환했다.
- 500/502/503/504에 대해 최대 3회, 2초·4초 백오프 재시도를 추가했다. 모델 호출 시도 횟수는 `nl2sql_log.jsonl`의 `model_attempts`에 기록한다.
